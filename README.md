# Bryce Digital

Portfolio and marketing site for Bryce Digital: custom dashboards, client portals and the integrations that feed them, mostly into NetSuite, Salesforce and Stripe.

It's archived, so it won't get any more updates.

## Stack

Next.js (App Router), TypeScript, Tailwind and Framer Motion. The `supabase/` folder holds the backend config.

## Run it

```bash
npm install
npm run dev
```
